# movie-theater-reservation

How to Run

Download movie_theater.c and a compatible theater input file.
Open a terminal in the project directory.
Compile the program using GCC:
gcc movie_theater.c -o movie_theater
Run the program:
./movie_theater
Enter the name of your theater input file when prompted.
Follow the instructions to select and reserve seats.
Enter an output filename to save the updated seating arrangement.ns
